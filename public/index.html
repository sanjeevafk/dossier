Design Philosophy

Why traditional LLMs hallucinate viable startups.

Standard frontier models are RLHF-tuned for agreeable sycophancy. When you ask them about an idea, they flatter your assumptions instead of stress-testing fatal operational hazards.

Standard Frontier LLM
Sycophantic Validation

Praises every feature request, assumes linear market adoption, and quotes generic TAM numbers without verifying procurement or statutory friction.

Static Financial Models
Deterministic Illusions

Spreadsheets calculate uniform payback periods using static assumptions, ignoring tail churn events, CAC inflation, and insolvent downside distributions.

Dossier Adversarial Swarm
Empirical Invariance & Proof

Deterministic Python sandbox Monte Carlo, Razorpay merchant demand grounding, Loot Drop failure traps, and Epistemic DAG verification with anti-sycophancy caps.

Agent Specifications

Six specialized adversarial agents.

Each agent operates under a strict mathematical and operational charter, probing distinct failure vectors before reaching final consensus.

Agent 00 Synthesizer
Executive Synthesizer

Establishes domain priors, identifies procurement cycles, and synthesizes crossfire arguments into actionable strategic verdicts.

Agent 01 Contrarian
The Skeptic (Red Team)

Probes existential distribution risks, enterprise sales deadlocks, incumbent bundling traps, and uncompensated tail risks.

Agent 02 Engineering
Technical Architect

Analyzes latency, workflow integration, model inference costs, API dependency moats, and data residency constraints.

Agent 03 Oracle & recon
Market Recon

Queries Polymarket betting volumes, live news headlines, developer traction signals, and competitor displacement friction.

Agent 04 Reality check
Customer Advocate

Matches propositions against real merchant problem catalogs (Razorpay Fix My Itch) and validates daily workflow switching friction.

Agent 05 Venture capital
Financial Analyst

Calibrates CAC payback bounds, gross margin thresholds, and verifies scores against isolated Python Monte Carlo output.
