# TrueForge Agent

An AI agent built on [TrueForge](https://github.com/truefoundry/trueforge) harness for the WeMakeDevs Agent Harness Hackathon.

## Overview
- **Harness:** TrueForge
- **Tool Protocol:** Model Context Protocol (MCP)
- **Safety:** Human-in-the-loop approval gates for sensitive actions
- **Code Execution:** Sandboxed runtime
